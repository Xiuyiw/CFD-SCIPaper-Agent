# Changelog

## [0.26.0] — 2026-10-28

### Added

- Explicit initial manuscript figure selection for surface studies, including a table-led zero-figure
  choice while retaining the generated field and distribution data.
- Paired regional changes and budget decomposition can share a diagnostic canvas. The Python
  attachment API retains panel selection, style and source-driven author-local refresh recipes.
- A public research-expression example connects original constructed face arrays, calculations,
  complementary panels, host-authored prose, native tables and a source-update continuation.

### Fixed

- Research builds honor explicit paragraph/table/figure order through the formal Word exporter,
  including first builds without an author-recovery file.
- Body indentation and before/after spacing stay scoped to prose, rather than leaking into figure
  and equation paragraphs. Shared table units appear in headers without rounding the source data.
- Diagnostic refresh reads metadata from registered recipes and retains author captions, scripts,
  drafts and display precision for the same bound observation.
- Near-equal paired-change annotations use separate vertical alignments without moving data,
  changing axis limits or replacing the author's plotting style.
- Budget compositions retain all signed endpoints for valid negative source, storage or remainder
  terms. Custom legends and captions name the actual summed terms, including nonzero storage/source.
- Original-face maps size their automatic y-tick locator to the actual panel height, retaining
  nonoverlapping labels with the bundled serif fallback when Times New Roman is unavailable.
- Bounded figure-recipe diagnostics retain the beginning and end of stderr, so repeated font warnings
  no longer hide the actual rendering exception.

## [0.25.0] — 2026-10-26

### Added

- `report_task` and CLI/MCP report input accept a figure plan: exact-case x/y response bindings,
  multiple series and multi-column complementary panels consume the same calculations as writing.
- Original-face field/diagnostic composites combine two common-scale maps, declared region
  outlines and height-resolved positive, negative and net transfers, joined by explicit case IDs.
- A portable constructed-report example produces the bound panels, native table, three supplied
  author sections and editable Word output through installed product entry points.

### Fixed

- Report continuation preserves and executes the author's local plotting script with freshly
  computed source rows; it does not silently replace that script with the template.
- Dimensionless source unit `1` remains in calculation metadata without appearing as a prose suffix.
- Unit-changing report continuations no longer reuse author-script axes with obsolete units;
  a new figure configuration is required before migrating author styling.
- Assembled author captions, including resolved value tokens, populate the current report
  context and figure summary rather than leaving the preparation caption behind.

### Evaluation

- Known cooling tasks exercised report-bound thermal/hydraulic responses and original-face
  field/height diagnostics. Editable mechanism artwork used the existing Studio exchange path.
  These are complementary studies in an existing project, not independent scientific validation.
- Scientific interpretation remains host/author work. Mature real transient/multiphase CFD
  evaluation remains open. Release checks and evaluation scope are recorded in the
  [version notes](docs/releases/v0.25.0.md).

  projections or empty templates. Separate numeric refresh from changes requiring interpretation.
- Keep method/Discussion evidence requirements aligned with section roles; keep detailed
  source records in located reports rather than repeating them in every host response.
- Avoid cancellation when resolving comparison ratios from retained raw parent values.
- Resolve current execution declarations during portability checks instead of scanning old
  snapshots; initialize NumPy before the Windows stdio reader starts.

### Evaluation

- Known-project flow and heat-transfer paths, managed author-state relocation and an actual
  bounded second-host study are evaluated separately from software/installation checks.
- Real transient/multiphase CFD evaluation remains open because suitable mature materials

- Recover local `Figure`/`Fig.` presentation changes and unambiguous complete bound-clause
  deletions without treating changed identifiers or numbers as ordinary wording.
- Preserve Word-localized style identities and distinguish unit typography from changed values.
- Keep LaTeX captions with their figures and separate table notes from bottom rules.

### Evaluation

- A real five-page cooling manuscript completed an actual author Word return: wording, local
  reference abbreviations, caption deletion and an anchored caption comment were recovered.
  The host shortened the commented caption in the continuing source; this is host writing,
  not automatic scientific revision. Actual Word pages and a five-page IEEEtran-based TeX
  output were inspected. Template-specific compliance and arbitrary Word round-trip are not implied.
- See the [release notes](docs/releases/v0.23.0.md) for validation results and supported boundaries.

  and verify literature excerpts at declared source lines or extracted PDF pages.

  refresh current recipe inputs after a diagnostic source-path change.
- Publish attached diagnostic results and cross-section aliases before first writing, rather
  than leaving only old surface statistics in the prepared reading context.
- Verify geometric polygon partitions by actual intersections/unions; reject origin-dependent
  absolute-temperature integral comparisons while retaining ordinary mean-temperature changes.
- Separate adjacent Word table captions from the preceding table without resetting body styles.

### Evaluation

- A real four-case cooling task exercised regional temperatures, native interface budgets,
  signed reconstructed paths, complementary figures, Word output and targeted refresh.
- Isolated first writers using the preceding and candidate tools reached similar supported
  scientific interpretations. The new tools replaced task-specific mathematical processing
  and a scalar bridge; no unmeasured time saving or superior autonomous discovery is claimed.
- Existing transient thermal-model records demonstrated the difference between common-time
  and own-event comparisons. This is not multiphase CFD or independent model validation.
- See the [release notes](docs/releases/v0.22.0.md) for supported scope and actual limitations.

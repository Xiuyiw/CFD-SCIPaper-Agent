# V0.3 Evidence-to-Figure-and-Paragraph Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Deliver a tested V0.3 vertical slice that qualifies canonical exported CFD observations,
locks a defensible QoI, produces one evidence-bound SVG/PNG figure, and writes one numerically
backlinked results paragraph.

**Architecture:** Reuse V0.2 project state, scientific primitives, FigureContract, and delivery QA.
Add one internal `qualification` package for canonical observations, scientific qualification,
candidate/locked QoI, claim ceiling, artifact fingerprints, and orchestration. Keep deterministic
figure and paragraph renderers in `publication`; expose them through four thin Skills and the existing
CLI without introducing a new runtime or registry.

**Tech Stack:** Python 3.10–3.12, Pydantic 2, Typer, SQLite/ProjectStore, standard-library CSV/JSON,
Matplotlib 3.8+, pytest, Ruff.

**Approved design:**
`docs/superpowers/specs/2026-09-01-v0.3-evidence-to-figure-and-paragraph-design.md`

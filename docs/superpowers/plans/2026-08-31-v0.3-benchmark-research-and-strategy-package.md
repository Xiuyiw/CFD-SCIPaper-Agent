# V0.3 Benchmark Research and Strategy Package Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `subagent-driven-development` only when the
> author explicitly delegates independent tracks; otherwise use `executing-plans` task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 系统比较可验证的开源项目和公开商业工作流，形成包含代码级借鉴依据、内置技能
体系、V0.3+产品设计、路线图、统一总则和外部AI评审提示词的完整策略包。

**Architecture:** 采用模块优先的双层漏斗：先按七条能力轨道发现30–50个候选，再选择约
12–18个开源项目做代码级深读，并对5–8个闭源产品做官方公开工作流分析。研究事实、主控
推断、迁移建议和拒绝理由分层记录；深读仓库只放在系统临时目录，最终材料写入独立研究分支。

**Tech Stack:** Git、GitHub CLI、Web/官方文档、Python 3.10+标准库、Markdown、JSON/JSONL、
CSV、PowerShell；不新增V0.2.0运行时依赖。

**Mandatory scope control:** 每个实施提示必须以`$stop-that-shit change --`边界启动，每个只读
复审提示必须以`$stop-that-shit review --`边界启动。STOP THAT SHIT不是附加安全检查，而是
本计划的范围控制器：完成被批准的交付和必要后果后立即停止。

```powershell
$rows=Get-Content 'docs/research/v0.3-strategy-package/candidate_catalog.jsonl' |
  ForEach-Object { $_ | ConvertFrom-Json }
$allowed=@('open-source','commercial-public','standard','academic-code')
$required=@('cfd-adapters','scientific-analysis','figures','writing','agent-rag','skills','quality-export')
if($rows.Count -lt 30 -or $rows.Count -gt 50){ throw "candidate count=$($rows.Count)" }

  throw 'invalid URL or source_type'

if($missing){ throw "missing tracks: $($missing -join ', ')" }
"candidates=$($rows.Count); tracks=$($tracks.Count)"
```

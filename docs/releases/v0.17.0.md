# v0.17.0 saved transient evidence and portable writing

This release connects time-dependent exported results to the existing analysis, numerical binding,
subsection writing and editable Word paths. It does not add a solver or require a provider SDK.

## Implemented

- `temporal` calculations map declared time/value columns in CSV or aligned one-dimensional NPZ.
  Seconds must be finite and strictly increasing in source order. Explicit window endpoints must
  be observed samples; the software does not sort, deduplicate or silently interpolate them.
- Instantaneous series provide trapezoidal integrals and time-weighted means on actual intervals,
  saved extrema, earliest sampled maximum time and optional first qualifying threshold sample.
  Cumulative series provide the endpoint increment, not a second integral or temporal mean.
- Derived results retain source locations, physical units and selected time windows. Comparisons
  require compatible definitions and windows; missing threshold events remain missing.
- Analysis proposals and section result references consume the same operators. Computed metrics
  appear in prose and native Word tables without manually copying their values.
- Specialist guidance and an invented, portable thermal tutorial demonstrate a three-panel
  figure, editable source/graphics and actual subsection export.

See [the tutorial](../tutorials/transient-writing.md) and
[the recorded example](../../examples/transient-writing/README.md).

## Real-material exercise

A first-writing exercise used existing four-combination, 30-cell material diagnostics over the
common 0–250 s saved window. The generated subsection identified a capacity-dependent reversal
of the Cell 3 conductivity effect and distinguished algebraic interaction from a local heat-flow
mechanism. Source-bound endpoint and time-mean values were recomputed; the original materials and
solver outputs were unchanged. A separate frozen single-cell history exercised actual nonuniform
saved times and instantaneous/cumulative heat inputs. These two models were not combined into one
validation chain. Public examples contain invented data, not the private project assets.

The private exercise used a Codex host and preserved its first output. It is a known-project
workflow test, not independent experimental validation, an improvement comparison against v0.16,
or a demonstration that every model provider produces equivalent scientific reasoning.

## Remaining scope

Portable files and CLI calls support different tool-capable hosts; web models can review evidence
and return draft JSON for local assembly. No multi-provider scientific comparison was executed in
this release. Native Fluent/STAR/COMSOL extraction, arbitrary event interpolation, true multiphase
validation, author-edited Word return and autonomous full-paper reasoning remain outside this slice.

# v0.18.0 complementary observations for scientific writing

The release extends the existing host-assisted analysis and manuscript workflow. It connects
source-defined reference comparisons and complementary numerical panels with a coherent scientific
argument, while retaining author selection and interpretation.

## Implemented

- `reference_range`: value/reference/lower/upper or value/reference/half_width, matching declared
  units and explicit reported-range, figure-reading-envelope or declared-bound semantics.
  Difference and signed outside_distance are calculated from source values; temperature differences
  are in K. Missing bounds do not become zero or an overall model-pass decision.
- A shared calculation-declaration call connects automatic figures and writing. This fixes the
  v0.17 default temporal-plot route that omitted window/cumulative/threshold options and labels.
- Optional analysis `evidence_panels` produces temporal profiles and supplied reference ranges in
  complementary panels. Outputs retain exact source records, source-data CSV, standalone editable
  Python, SVG/PDF/PNG/TIFF and measured layout/physical sizing.
- Packaged multi-observation guidance links comparison definitions, discriminating evidence,
  physical alternatives and literature discussion across neighboring manuscript sections.
- [A recorded invented tutorial](../../examples/multi-observation/README.md) exercises intake,
  proposal compilation, figures, four-section assembly, numerical binding and editable Word output.

## Actual scientific exercise

The same raw cell-reconstruction materials and literature were given to isolated hosts using an
installed v0.17 baseline and installed v0.18 candidate. Both completed Methods, Results, Discussion
and a short Conclusion. An independent review found no decisive arithmetic error, but mixed
scientific strengths: the candidate focused observation definitions and opposing evidence; the
baseline retained more saved-history, peak and energy-path evidence. This is not proof of uniform
first-draft improvement or independent physical validation.

One separate feedback revision used the existing 780 W history over actual saved endpoints inside
the specified pre-onset reading window. Both modeled surface minima remained above their supplied
figure-reading upper bounds, strengthening a specific argument against time-offset selection alone
as the explanation. The check does not reconcile measurement support or identify a unique faulty
parameter. First drafts remain intact; feedback gains are not counted as new first-pass gains.

A separate chip-cooling regression reproduced a previously declared temperature-rise screening
band and retained 43 existing numerical bindings. Its reference operator remains partly ambiguous;
screening is not experimental validation. No original solver/project file was changed or rerun.

## Boundaries

Only two numerical panel families are implemented, not an arbitrary figure editor or field
extractor. Cross-operation/chained scalar comparisons and automatic Word-edit merging remain
outside this slice. No cross-provider scientific trial was run; the portable file/CLI task path
remains available. Software tests and readable Word output do not establish submission readiness,
model accuracy, new experimental evidence or autonomous full-paper reasoning.

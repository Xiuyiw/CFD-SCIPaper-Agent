# CFD-Paper-Agent v0.1.0 — Initial Public Preview

Release date: 2026-08-30.

v0.1.0 opens a small, executable part of CFD-Paper-Agent for public demonstration and feedback.
It establishes local project state, file inspection, checkpoints, and evidence-bounded ranking of
topic candidates supplied by the author. It does not produce a complete manuscript.

## Available

- Installable `cfdpaper` CLI targeting CPython 3.10–3.12.
- `init` and `status` for project-local SQLite state.
- Incremental `inspect` with explicit stale-source tracking and strict/fast hash modes.
- `plan` for schema-v1 author-supplied candidates, including a JSON ranking report.
- Resumable inspection and planning checkpoints.
- Explicit author approval metadata without downstream manuscript execution.
- A copied-directory [synthetic Quickstart](../../examples/quickstart/README.md).

## Known limitations

- Indexing a result file does not make it verified scientific evidence.
- The public CLI has no v0.1.0 command for ingesting structured evidence records.
- `analyze`, `figure`, `write`, `review`, `revise`, and `export` are roadmap placeholders and exit
  non-zero.
- Solver-native extraction is not generally supported.
- Planning performs a fast incremental reinspection; unchanged files are not strictly rehashed in
  that step.
- The preview does not validate conclusions, make autonomous publication decisions, or guarantee
  suitability for a solver or physical domain.

## Quickstart result

The synthetic example runs `init → inspect → plan → status` from a copied temporary
directory. Because the public CLI does not promote indexed files into evidence records, the
expected plan outcome is `missing-evidence`. A report and checkpoint are still created, making the
scientific boundary inspectable and resumable.

## Verification boundary

The preparation gate includes more than 400 automated tests, Ruff lint/format checks, a copied
Quickstart regression, package smoke testing, and public-tree checks. Exact platform jobs and test
counts are recorded by the release commit and CI; a platform is supported only when its release
job passes.

## Next target

v0.2.0 targets automatic generation of 2–4 evidence-bounded topic candidates from the current
project evidence state. Candidates will still require author review and explicit approval. This
target does not imply automatic analysis, writing, or publication.

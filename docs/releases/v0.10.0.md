# v0.10.0 — Spatial evidence and scientific explanation

Version 0.10 is in release preparation. It connects explicit spatial weighting to host-written
interpretation, reproducible field figures and readable Word output, while preserving the
existing multi-section, literature and review workflows.

## What's new

- **Explicit area/volume weighting:** `weighted_population` calculates weighted mean,
  population SD and measure sum from declared value and strictly positive area/volume columns.
  Results retain units and source records and bind to prose and native Word tables.
- **Temperature semantics:** absolute-temperature means retain their scale; temperature SD
  is a difference in K. Translating Celsius values to Kelvin does not change their SD.
- **Spatial-reasoning guidance:** bundled QoI and writing skills help the host interpret field
  location and extent alongside mean, spread and extrema, with definitions placed where useful
  rather than repeated throughout the prose.
- **Portable field-and-Word example:** unequal-area wall facets and a separate volume example
  accompany an actual source-rendered map, editable SVG/PDF, PNG/TIFF, CSV and runnable local
  plotting code. The wall map preserves physical facet widths and one comparison color scale.
- **Document refinements:** numeric table headers now align with their column values;
  Markdown table numbers appear once, and supplied artwork no longer receives an automatic
  pending-figure instruction.

## Try the spatial example

From the matching checkout, install Word support and run:

```text
python -m pip install ".[docs]"
python examples/spatial-diagnostics/run_example.py output/spatial-demo
cfdpaper write . --artifact results-section --package output/spatial-demo/section --docx --layout near-reference --output output/spatial-demo/spatial-diagnostics.docx
```

Use fresh output paths. Add `--pdf-preview` to the final command for a PDF preview with an
existing LibreOffice installation. The [example tutorial](../../examples/spatial-diagnostics/README.md)
covers relocation, local figure edits, known answers and a new host attempt via `--prepare-only`.
The published v0.9.0 wheel does not contain the new weighted operator.

Default execution replays a **recorded guided host draft** using prescribed analytical fields.
It does not invoke a model on each run. The wall example shows how a lower mean can coexist with
a hotter terminal region and a larger spatial SD; the independent volume example checks another
measure, not a wall-cooling mechanism. These are synthetic teaching data, not CFD results or
experimental validation.

## Scope

Weights, units, domain coverage and the meaning of the element values must be declared and
assessed by the host and author. Invalid weights require correction; missing selected values
are not silently filtered out. Spatial population SD is not an uncertainty estimate, and
statistics of element averages do not reconstruct within-element fluctuations.

This increment adds no automatic CV, quantiles, flux integration, native solver intake or
general field engine. Source-bound values can refresh after relocation and source changes;
interpretations still require host/author review. Whole-paper review, selected editing, shared
literature, paired comparisons and optional numeric CSL formatting remain available as described
in the [v0.9.0 notes](v0.9.0.md). Root journal `revise` and submission `export`, automatic
full-paper reasoning and broad heterogeneous CFD validation remain outside this release.

# v0.19.0 source parameters and paired observations

This version strengthens the existing scientific analysis and manuscript workflow.
It keeps selected numerical methods attached to their configuration source and makes paired
model/reference contrasts reproducible from both original observations.

## Implemented

- `json_value_ref` resolves a finite numeric JSON field through an exact pointer, with explicit
  units and precision. Preparation exposes its current value; prose, native tables/equations
  and cross-section bindings refresh it during reassembly. The manuscript seed includes the
  declared JSON dependency without a separate hand-maintained source list.
- `paired_reference_change` computes model/reference member differences and conservative
  endpoint envelopes from two explicit source records per group. It retains both members'
  values and locations. Temperature contrasts use K; percentages and invented confidence
  intervals are not produced.
- The finite reference panel renders these contrasts using the same results as numeric prose.
  Source CSV, standalone Python and SVG/PDF/PNG/TIFF preserve the raw member context.
- Packaged methods guidance prioritizes the actual caller, effective settings and necessary
  numerical/model choices. Multi-observation guidance distinguishes offset cancellation,
  fixed-time states and each case's own event-relative state.
- A recorded [public tutorial](../../examples/paired-observations/README.md) connects analysis,
  a paired panel, a native absolute-state table, source-bound numerical settings and four sections.

## Actual scientific exercise

Existing controlled thermal-model perturbation results were supplied to isolated first-writing
hosts using installed v0.18 and v0.19 packages, with the same histories, configurations, active
method sources and literature. This is a new source/transport diagnostic task, not a replay of
the previous event/temperature reconstruction draft. No new solution or fit was run.

One independent review found no important numerical error, but mixed strengths. The candidate
explained reaction feedback and coupling between transport and reconstructed observations more
clearly; the baseline retained an independent boundary-exchange diagnostic and a more revealing
late-time plot. Both still needed a fuller effective mathematical model and cleaner bibliographic
display. The candidate also had avoidable terminology and page-layout weaknesses. Source-bound
parameters were used, but this single host-assisted trial does not establish uniform first-draft
superiority or automatic scientific reasoning. First outputs remain unchanged; there was no
feedback rewrite counted as a product gain. The resulting methods, figure-reading and bibliography
lessons were added to the existing packaged guidance, not claimed as a new validated trial.

A targeted numerical regression also used existing battery reference observations and chip-cooling
setup parameters. It checked paired arithmetic and JSON binding without changing original files;
these are software/source regressions, not independent cross-domain physical validation.

## Scope

Exact numeric bindings do not discover active overrides or establish physical truth. Paired
contrast agreement can conceal absolute offsets; original observations remain necessary.
The envelope is conservative endpoint subtraction, not statistical uncertainty. Controlled
term deletion discriminates effects within the model, not measured material properties.
General native solver extraction, automatic Word-edit merging and independent cross-provider
scientific equivalence are outside this slice.

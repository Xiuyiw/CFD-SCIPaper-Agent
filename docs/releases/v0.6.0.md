# v0.6.0 — From existing materials to a scientific analysis

Start with exported tables and method notes, rather than preparing a complete input
schema yourself. Your host AI proposes a small set of evidence-grounded analyses;
you select a direction, and CFD-Paper-Agent connects the declared calculations to
an editable results subsection.

## What is new

- **Material intake:** inspect CSV columns, explicit units, missing values and readable
  source notes; preserve useful existing raster figures.
- **Portable analysis tasks:** carry the sources, analysis and figure-selection skills
  to a local host AI. The host maps physical definitions and proposes one to three
  useful analyses, asking only about essential gaps.
- **Source-linked execution:** author selection runs supported population or partition
  calculations and binds the results into the existing subsection-writing workflow.
- **Choose the right expression:** use a plot, concise prose or a native table when it
  fits the scientific relationship. Custom figures remain explicit production tasks;
  the software does not substitute a default scatter plot for an unsupported design.
- **Self-contained writing:** writing tasks include their skill and mechanism reference,
  including editable tables, mathematical expressions and literature-role guidance.
- **Body formatting:** configurable two-character first-line indentation and zero
  before/after paragraph spacing, without changing captions, headings or table cells.

## Try it

Install this tag or its wheel with the `docs` extra, then follow the
[material-analysis tutorial](../../examples/material-analysis/README.md).
The release example ZIP includes synthetic source tables, a runnable replay,
an editable Word subsection and its PDF preview. The default compact table places
area, total heat rate and average heat flux together. Optional plot output retains
the existing four-format figure path.

The offline example uses recorded host responses for reproducibility. For a real
study, give the generated task to your host AI and review its proposed analysis.

## Scope

Supported new inputs are CSV tables, readable JSON/Markdown/text notes and raster
figures. Scientific definitions and comparisons are established by the author and
host, not inferred from column names alone. Numerical operations remain the declared
population and partition calculations; missing definitions or incomparable selected
cases require correction before execution.

This release does not add native solver extraction, automatic complex mechanism
figures, full-manuscript generation, literature verification or new heterogeneous
project validation. It does not run CFD simulations.

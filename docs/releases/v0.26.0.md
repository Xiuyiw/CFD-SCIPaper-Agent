# v0.26.0 — Source-bound research expression and formal manuscripts

This release connects figure selection, complementary diagnostic composition and formal Word
layout to the existing source-driven research workspace. The same calculations supply figure
source rows, native tables and numerical references in host-authored prose; continuation retains
the author's current plotting script and drafts rather than rebuilding their style from a template.

## What changes in a research task

- Choose the initial manuscript figures with `study.selected_figures`. Omit it to retain the existing
  field/distribution pair, select either in the intended order, or use `[]` for a table-led argument.
  Generated observations remain available without automatically becoming main figures.
- Combine explicit paired regional changes and a budget decomposition with
  `attach_research_diagnostics(..., combine=True, figure_id=..., panel_ids=..., style=...)`.
  Panel selection affects the composition, not the numerical evidence available to writing.
  The local script retains the selection and reads the current workspace sources on later builds.
- Put shared display units in native table headers with `column_units`. Source units and numerical
  precision remain intact; the same bound observation retains its author-selected display precision
  during refresh.
- Use explicit paragraph IDs and `block_order` to arrange prose, figures and tables through the
  formal Word exporter, including a first build without an author-recovery file. Body indentation
  and paragraph spacing no longer leak into image or equation paragraphs.
- Continue diagnostic figures through their registered recipes. Current figure metadata, captions,
  drafts and author-local scripts stay connected; unrelated recipe outputs need not be regenerated.

The diagnostic renderer also separates near-equal paired-change annotations without moving the
data. Budget compositions retain legal negative source, storage and remainder endpoints, and their
legends identify the actual sums even when the author supplies custom component names.
Original-face maps also adapt their automatic y ticks to the actual panel height, including the
bundled serif fallback on systems without Times New Roman. Recipe failures retain the end of the
traceback even when repeated warnings fill the diagnostic log.

## Try the public example

Install the matching wheel with `[docs]`, copy `examples/research-expression` from the matching
source archive or examples bundle, and choose a new, reasonably short output directory:

```console
python /path/to/research-expression/run_example.py /path/to/new-output
```

Open `new-output/candidate/manuscript.docx` and `new-output/refreshed/manuscript.docx`. The first
contains one complementary two-panel figure and two native tables. The second rebuilds the
source-bound values after an isolated source edit while retaining a local script style edit and
the supplied author drafts. SVG/PDF, PNG/TIFF, original and paired-change CSVs and runnable
`plot.py` remain with the figure. See the [example guide](../../examples/research-expression/README.md)
and [research-workspace guide](../research-workspace.md) for continuation.

The inputs are constructed unequal-area faces and separately prescribed budget tables. The
example author supplies the question and scientific wording. These materials demonstrate weighted
calculation, binding, composition and continuation; their juxtaposition is not evidence of a causal
heat-transfer mechanism.

## Evaluation and scope

A known cooling task exercised a connected four-page research unit with three complementary
figures, two native tables and a native equation. Actual Word/PDF pages were inspected. An isolated
source-value perturbation updated the affected field and regional/budget figures and bound text,
while retaining the unrelated height-resolved figure, author drafts and local scripts. This was
software continuation, not another CFD operating condition or independent validation.

The public replay was also run from an installed wheel outside the source checkout. It is part of
the package smoke alongside the Windows/Linux Python 3.10–3.12 test matrix. Completed release runs
and distributions are linked from the
[v0.26.0 GitHub Release](https://github.com/Xiuyiw/CFD-SCIPaper-Agent/releases/tag/v0.26.0).

The host and author still choose the scientific argument, assess explanations and inspect final
figures and pages. P04's final figures remain the internal quality floor; passing an export or a
synthetic replay does not certify that quality for arbitrary inputs. Full geometry-specific
mechanism-diagram quality and mature real transient/multiphase CFD evaluation remain open.

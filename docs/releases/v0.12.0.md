# v0.12.0 — Connected scientific writing

This release reduces manual preparation between exported CFD tables, connected manuscript
sections and editable Word output.

## What changes

- **Long tables:** exact `row_filters` select records before numeric parsing and membership
  checks. `unit_column` checks the selected units. Calculations retain original row locations;
  no pivot, inferred conversion or separate per-metric CSV is required.
- **Current writing context:** `write --artifact manuscript --context-for SECTION` collects
  current related passages, calculated evidence, located literature and manuscript keywords.
  Optional partial draft mappings let the host write sections progressively.
- **Concise values:** a paragraph may declare `shared_unit` when that unit is explicitly stated
  and applies to every bound number. Tables and evidence records retain their complete units.
- **Word pagination:** opt-in `figure_caption_pagination: "allow-split"` and
  `table_pagination: "allow-split"` avoid unnecessary gaps while preserving the existing defaults.

Run the [connected-writing example](../../examples/connected-writing/README.md) for a three-section
Methods–Results–Discussion manuscript. It includes a native table, relocation instructions and
a source-change replay. Its drafts are recorded synthetic inputs, not live model generation.

## Evidence and scope

An unchanged mixed-unit P04 table exercised the new selection path without manually pivoting the
source. A paired known-project first-draft comparison found useful context/intake improvements,
but did not establish a general scientific-depth improvement. Fixed-content Word checks confirmed
more practical caption pagination; scientific explanations remain the host's and author's work.

Raw definitions, comparison validity and missing physical evidence still require judgment.
Numbers refresh when sources change; literal explanations and figures do not rewrite themselves.
Native solver extraction, transient/multiphase generalization and Word-only edit return remain
outside this release. See [limitations](../limitations.md).

## Installation

Use Python 3.10–3.12 and the matching release wheel with its `[docs]` extra, or run
`python -m pip install ".[docs]"` from the v0.12.0 checkout.

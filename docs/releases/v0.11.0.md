# v0.11.0 — Linked diagnostics and manuscript updates

This release makes it easier to compare calculated CFD diagnostics without copying rounded
intermediate values into a new table, and to see which manuscript passages need attention when
the underlying results change.

## New capabilities

- Compare two compatible computed scalars using `result_comparisons`. Both upstream sources,
  the physical domain and the comparison definition remain attached to the result.
- Select scalar records or compute paired changes directly in material-analysis proposals.
  Absolute-temperature differences use K; a relative change needs a defined temperature reference.
- Propagate updated numerical bindings into subsection prose, native tables and other sections.
  Existing change reports include old/new unrounded values, affected passages and associated
  figure captions. A changed difference sign prompts interpretation review, not an automatic rewrite.
- Carry declared source width, minimum font size and target width from external figure deliveries
  into Word. Effective font size reflects the actual scaling; undeclared font size remains unknown.
- Display supported scaled molar-flow units, including `× 10⁻⁶ kgmol·s⁻¹`, with nonbreaking
  number/unit groups in Word.

## Try it

Install the matching checkout with `python -m pip install ".[docs]"`, or install the release wheel
with its `[docs]` extra. Run the [linked example](../../examples/spatial-diagnostics/README.md):

```text
python examples/spatial-diagnostics/run_linked_example.py output/linked-demo
cfdpaper write . --artifact results-section --package output/linked-demo/section --docx --output output/linked-demo/comparison.docx
```

The example uses analytical wall fields and a recorded paragraph. It compares a lower weighted
mean with greater spatial variation; it is not a new CFD solution or an AI call on every run.

## Scope

Comparisons are shallow: they do not accept other comparisons as inputs or infer physical
comparability. Numerical updates do not rewrite explanations or regenerate supplied figures.
Mixed-unit long tables still need explicit preparation, and scientific interpretation and final
page review remain author/host responsibilities. Known-project trials demonstrated useful data
handling improvements but did not establish a systematic gain in scientific writing depth.

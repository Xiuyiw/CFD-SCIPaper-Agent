# v0.7.0 — Connected manuscript workspaces and editable drawing tasks

Candidate release notes. This version coordinates host-authored sections around a shared
paper spine and carries their evidence, drafts and writing instructions into a portable workspace.
External drawing tasks connect that workflow to editable artwork produced by the host's tools.

## What is new

- **Multi-section workspace:** prepare section tasks with shared terminology, section duties
  and paper-spine context; assemble host-authored drafts using the existing source-linked
  calculations and export editable Word prose, native tables and structured equations.
- **Cross-chapter references:** supported figure, table and equation tokens receive global
  numbering in spine order. Qualified `section_id/local_id` references work forwards and
  backwards and update when sections are reordered.
- **Portable continued editing:** assembled candidates retain local inputs, drafts, source
  files, Skills and a `CONTINUE.md` entry point. Move the whole candidate, edit a section
  and assemble a new output without the original project directory.
- **Methods guidance:** writing tasks carry a dedicated reference for organizing supplied
  geometry, models, boundary conditions, numerical methods and verification evidence,
  distinguishing evidence absent from the task package from evidence absent from the study.
- **External drawing-task exchange:** package data, conceptual or hybrid requests with
  adapted host guidance; import Python, SVG or uncompressed draw.io editing sources,
  previews and listed supporting files. The source remains available for focused author edits.
- **Editable document details:** structured dot and overbar notation, section-aware object
  placement and table-note adjacency extend the existing Word rendering path.

## Try it

Use a v0.7 checkout or a wheel built from the same version with the `docs` extra, then follow
the [manuscript workspace tutorial](../../examples/manuscript-workspace/README.md).
The v0.6.0 wheel does not contain this workflow. The tutorial supplies a public analytical
reference and three sample drafts, covering preparation, assembly, DOCX export and continuation
from a moved workspace. PDF preview requires an existing LibreOffice installation.

For an actual study, give the generated `TASK.md` and section tasks to your host AI and review
its prose against the supplied evidence. See the
[host drawing guidance](../../skills/cfd-figure-production/references/external-backends.md)
for external figure production and editable returns.

## Scope

The CLI prepares and assembles writing tasks; the host and author supply scientific prose and
judgment. Reassembly updates supported references and bound numerical values, not literal
numbers, interpretations or hand-written figure references in free prose. Word-only edits must
be reconciled into the local drafts before re-exporting. Importing a drawing does not execute
its scripts or establish scientific or visual approval.

The public example demonstrates multi-section software behavior, not a complete publishable
paper or complex mechanism-figure quality. This version does not add autonomous full-paper
argumentation, verified literature management, automatic complex mechanism graphics, native
solver extraction or broad heterogeneous scientific validation. It does not run CFD simulations.

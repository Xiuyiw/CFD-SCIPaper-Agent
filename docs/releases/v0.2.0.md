# CFD-Paper-Agent v0.2.0 — Evidence-bounded topic generation

Released: 2026-08-31

v0.2.0 extends the public planning workflow from ranking author-supplied candidates to generating
two to four provisional research topics from mature structured CFD evidence. The release remains
author-in-the-loop and stops before analysis, figure production, or manuscript writing.

## Added

- Automatic offline discovery of matched-comparison, ordered-response, and coupled-association
  opportunities.
- Candidate-to-evidence provenance, scientific claim ceilings, prohibited inferences, and minimum
  missing-data reporting.
- Structured QoI-definition and case-level convergence/conservation assessments in local SQLite
  state.
- Deterministic artifact reuse, explicit regeneration, author-file precedence, and recoverable
  planning checkpoints.
- Optional provider refinement with offline fallback; provider wording cannot change scientific
  facts or grant approval.
- Positive and negative end-to-end tests for mature and incomplete evidence states.

## Scientific boundary

Generation requires structured case, boundary, QoI, convergence, conservation, and provenance
records. `inspect` alone does not create those records. Incomplete, stale, incomparable, weakly
converged, or undefined evidence remains a gap and cannot be promoted by author approval.

The generated JSON artifacts are project-local persistence formats in v0.2.0, not stable public
interchange schemas. Native solver ingestion, `analyze`, `figure`, `write`, `review`, `revise`, and
`export` remain unavailable.

## Compatibility

- Python 3.10–3.12 on Windows and Linux through the published CI matrix.
- Existing v0.1.0 project databases migrate forward in place when opened by v0.2.0.
- Author-supplied candidate files and the v0.1.0 Quickstart remain supported.

Development pauses after v0.2.0. No v0.3.0 work is active without explicit author authorization.

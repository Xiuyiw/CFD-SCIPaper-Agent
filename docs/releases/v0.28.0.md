# v0.28.0 — Question-driven analysis and scientific revision

This release connects a useful supplementary analysis to figures and cross-section writing,
then provides a direct way to apply the host's explicit scientific revisions. It extends the
existing research workspace rather than creating another reasoning or document platform.

## Analyze the local and whole response together

`partition_change` integrates complete original-face partitions on a common planar NPZ surface.
It permits different meshes, uses actual physical areas, and retains the reference/comparison
means, weights, regional changes and weighted contributions. Fixed and source-following regions
have different physical meanings; changed area fractions cannot silently enter the fixed-weight
identity. Temperature components in K are not heat fractions or independent causal evidence.

The new `partition_contribution` panel shows the signed regional components with a whole-mean
marker. It composes with the existing regional-change and heat-budget panels, retaining source
data, editable SVG/PDF, previews and the author's local plotting entry point.

## Continue the scientific argument without file-moving scripts

Question reading follows selected owner evidence into all related sections and their aliases,
with stable paragraph IDs and related figure/table/equation definitions. Located line ranges and
Markdown headings return the requested material, not an unrelated opening excerpt.

`apply_research_revision` and `research --revision` accept host-provided paragraph/caption changes,
explicit evidence references and native inline mathematics. They check current author text and
write a fresh workspace while retaining untouched prose, block order, tables, formulas, citations,
author artwork sources and numbering. The existing MCP research function exposes these actions
alongside question reading and explicit same-ID artwork replacement.

## Try the complete task

With the matching checkout/archive and `.[docs,geometry]` installed:

```console
python examples/research-expression/run_example.py output/research-expression
python examples/mechanism-continuation/run_example.py output/research-expression output/mechanism
```

The continuation now computes regional temperature contributions, produces a complementary
three-panel figure and applies example-author revisions through the public API. Its controlled
source change is software continuation, not a new CFD operating point or a discovered mechanism.
See the [example guide](../../examples/mechanism-continuation/README.md) and
[workspace interface](../research-workspace.md).

The known cooling task uses existing Si/TIM faces, native budgets and signed conduction. The new
decomposition explains how weighted warming over the larger complementary region outweighs
source-following local cooling. It does not establish a higher heat-transfer coefficient or replace
the transport evidence. Scientific interpretation remains host/author work; unfamiliar-project
quality and real transient/multiphase CFD validation remain open.

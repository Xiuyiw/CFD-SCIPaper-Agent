# v0.4.0 — Figure-grounded subsection writing

This release connects existing figures and structured evidence to a host-AI writing
task, a resolved Markdown subsection, and an editable DOCX with actual images.

- One or multiple supplied figures and paragraph duties.
- Exact metric tokens, figure references, and supplied-literature citations.
- Separate manuscript prose, captions, and evidence notes.
- A self-contained external-review folder and suggestion import.
- An expanded existing writing skill, included with the four skills in the wheel.
- A runnable, public analytical pipe example with source data and four plot formats.

Follow the [section walkthrough](../../examples/section-writing/README.md).
Install the `docs` extra for Word export. Existing v0.3 qualification, analysis,
figure, and numeric-paragraph behavior remains available.

The host AI—not a deterministic template—provides the scientific interpretation.
Package checks validate declared relationships and tokens, not free-prose truth.
This release does not claim complete manuscript generation, arbitrary native
solver ingestion, or independent scientific approval.

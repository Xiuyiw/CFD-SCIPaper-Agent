# v0.9.0 — Evidence-linked manuscript review and revision

Version 0.9 connects a complete manuscript to external review and focused host editing,
while improving the calculations, portable figures and editable document output used in revision.

## What's new

- **Whole-paper review:** export reading text, source materials, literature excerpts and global
  paragraph/object locations. Return the complete report without reducing it to a short finding list.
- **Selected editing:** accept, reject or defer recommendations with exact quotations. Accepted
  items receive a separate portable authoring workspace; originals remain unchanged.
- **Scientific revision links:** `trace_evidence` lists paragraphs, tables and equations sharing
  declared evidence, including summaries. The host decides which interpretations need revision.
- **Source-bound comparisons:** `scalar_select` selects one record; `paired_change` computes exact
  pair differences and relative changes. Absolute-temperature ratios need an explicit rise reference.
- **Portable figure work:** source directory relationships survive task transfer. Preview reporting
  measures pixel dimensions and effective resolution at the intended printed width.
- **Word refinements:** native equation grouping/subscripts, compact-table pagination and Celsius
  labels. Existing material-analysis proposals retain their original comparison semantics.

## Try the review round trip

Install the matching wheel with the `docs` extra or run `python -m pip install ".[docs]"`
from a v0.9 checkout. Follow the [seven-section example](../../examples/literature-manuscript/README.md)
to create `my-manuscript`, then run from the checkout root:

```text
python examples/literature-manuscript/review_example.py my-manuscript review-demo
```

The example uses analytical data, supplied prose and an explicitly synthetic report. It exercises
the installed CLI, a relocated editing task, one authored wording edit and ordinary reassembly.
For a real review, give the complete report and generated task to your host AI and assess the
proposed changes with the author. See the tutorial for the three `review` commands.

## Scope

This is an author-in-the-loop writing and review workflow, not an autonomous scientific reviewer.
Evidence links locate declared dependencies; they do not prove causality or literature support.
The software does not run simulations, repair missing model/grid evidence, merge Word-only edits,
or certify submission readiness. Root journal `revise` and submission `export` remain roadmap work.

No API key, solver installation or database initialization is needed for the review route.
Word output uses the `docs` extra; PDF preview uses an existing LibreOffice installation.
Shared numeric CSL formatting continues to use optional Pandoc.

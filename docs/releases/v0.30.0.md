# v0.30.0 — Scientific definitions and targeted figure refresh

When one source or reference changes, recompute the physical result first, then update the
named cells consumed by the author's local plotting code. The same results supply caption
and paragraph bindings. A change in the reference can move several relative readings while
leaving the absolute measurements unchanged.

- **Analysis:** `activated_response_mean` evaluates a declared response on each selected face,
  then weights by the actual face areas. Averaging its inputs before applying a nonlinear law
  is a different operator. Finite results alone do not establish model validity.
- **Figures and writing:** `refresh-section` and `refresh_section_task` preserve the current
  author scripts and unaffected text. A local script must explicitly declare its inputs and
  outputs. An inspected image is not evidence that a subsequently redrawn image was inspected.
- **Changed definitions:** `--inspect-change` identifies affected evidence and its readers
  without drawing a new figure. After interpreting the new scope, the host can reconcile the
  changed readings and text with `--reconcile` in a fresh candidate. Neither step modifies
  the old manuscript. A different display transform is not a new observation; processed
  graphics alone cannot support quantitative validation.
- **Use it:** follow the [offline, synthetic before/after example](../../examples/material-analysis/README.md#refresh-an-authors-figure-caption-and-section).
  Then run `python examples/material-analysis/run_definition_refresh.py demo-refresh/after lower-region`
  to reconcile the complete-wall interpretation with a lower-region definition. The example retains
  the host's explicit revision next to the new Word candidate and leaves the old workspace untouched.
  Install the `docs` extra for editable Word candidates. This path does not patch arbitrary
  Word files or infer a scientific mechanism from a rendered curve.

Validation scope: the known-case replay is not a blind demonstration on an unfamiliar solver
or research system. Scientific interpretations remain subject to author review.

# v0.5.0 — From source tables to manuscript-ready elements

This release improves the path from mature CFD evidence to a readable, editable
results subsection. Authors and their host AI provide the scientific narrative;
the software connects its numerical anchors to source tables and assembles the
figures, tables and equations at manuscript scale.

## What is new

- **Current table values in the text.** Declare population or partition calculations
  and bind `result_ref` metrics to exact groups and fields. Assembly reads the CSV
  again and retains units, unrounded results and supporting records.
- **Four-format figures.** SVG/PDF/PNG/TIFF, source data and runnable scripts share
  physical dimensions and font settings. Local script refinements are preserved.
- **Editable document elements.** Native Word tables, display equations and inline
  mathematics replace image-only tables and code-like formula notation.
- **Size-aware layouts.** Place figures near their first reference or after the text;
  configure page margins, text sizes and figure widths in mm and pt. Known figure
  font sizes are checked at their actual embedded scale.
- **Optional PDF preview.** An installed LibreOffice renders an isolated document
  copy; DOCX export remains available without an office backend.

## Try it

Install from this tag or its wheel with the `docs` extra, then follow the
[subsection tutorial](../../examples/section-writing/README.md).
The release includes `cfd-paper-agent-0.5.0-example.zip`: a synthetic pipe-flow
example with source tables, scripts, four-format figures and both DOCX/PDF layouts.
Its narrative is a prewritten tutorial, not an independently generated research result.

The four bundled skills include runnable table-binding and structured-math examples
that work from the installed package without a source checkout.

## Scope

Scientific interpretation and final manuscript approval remain with the author.
The structured math format supports a finite set of expressions, not arbitrary
LaTeX. Figure font size cannot be certified when its source metadata is unknown.
This release does not add native solver ingestion, complete manuscript generation,
automatic literature verification or journal submission.

# v0.29.0 — Original fields to connected research figures

This release brings original-face diagnostics, actual figures and their current scientific
reading into the existing research workspace. It reduces proposal-file transcription and
connects the visible spatial response to the same regional quantities used in the manuscript.

## From the physical comparison to the figure

`compile_analysis` and `run_analysis_task` accept a host-supplied object or the existing JSON
file. `research_task` similarly accepts diagnostic objects. The host still chooses the research
question, comparison and physical definitions; the toolkit executes the supported analysis.
C/header material reading and located search do not compile UDFs or infer solver hooks.

The new `surface_partition_panel` selection combines original planar face-temperature maps,
their actual fixed/moving region outlines, and signed regional contributions. One/two comparisons
use two/four distinct sources and a shared Kelvin scale. Original polygons, values and physical
areas remain authoritative; display interpolation does not enter the reductions. Contributions
compose a mean-temperature change, not a heat budget or independent evidence of causation.

The renderer supplies editable SVG/PDF, PNG/TIFF, original-field and contribution CSVs, and a
local `plot.py`. Current preview, caption, dimensions, panel definitions and compact numerical
readings are returned to the host together. Small adjacent contributions use a leader when an
outside label would otherwise belong visually to the wrong segment.

## Continue after author and data edits

The retained author script remains the refresh entry point. Changed source values update the
figure and bindings, while existing interpretation is preserved for explicit host revision.
Redrawing also invalidates the old image-observation state: a newly generated image cannot
inherit an earlier claim of having been viewed. Unchanged figures and unrelated prose remain.
Automatic display precision preserves small nonzero readings; it does not claim extra accuracy.

## Run the public example

With the matching checkout/archive and `.[docs,geometry]` installed:

```console
python examples/research-expression/run_linked_surface_example.py output/linked-surface
```

The example creates two constructed 64-face fields, a three-panel figure and bound Word prose.
It then edits the local plotting style, changes a working copy of the source, and uses the same
public interfaces to refresh and explicitly revise the affected paragraph/caption. The controlled
+0.5 to −0.5 K reversal demonstrates software continuation, not a new physical operating point.
See the [example guide](../../examples/research-expression/README.md) and
[workspace interface](../research-workspace.md).

## Actual trial and remaining scope

A known cooling task linked four Si/TIM fields to a five-panel figure, a native table, an equation
and a three-page candidate. A second task reused the same interface on Cu/TIM fields with fixed
regions and a different comparison, producing a three-panel figure and two bound paragraphs.
Actual figure inspection exposed the small-contribution label ambiguity and led to the reusable
renderer repair, not a private image retouch. The original results and first outputs were retained.

These are known-project task replays, not blind validation or a blanket P04/Energy-level quality
guarantee. Scientific interpretation and publication suitability remain author-reviewed. The
external furnace trial, Fluent 2025 R1 compatibility and real transient/multiphase validation are
not closed by this release. No new solver run, paid host trial or fabricated acceptance is implied.

Supported-platform tests and installed-package examples are linked from the
[GitHub Release](https://github.com/Xiuyiw/CFD-SCIPaper-Agent/releases/tag/v0.29.0).

# v0.20.0 effective methods and saved contrasts

This version makes existing method definitions and discriminating saved observations easier
to bring into the scientific writing workflow. It also separates bibliographic metadata from
the finding a citation supports and adds an explicit, limited Word figure-placement option.

## Implemented

- Python materials expose a static lexical definition index. Exact qualified-name reads retain
  source lines, decorators and explicit truncation; missing or ambiguous names are reported.
  `cfdpaper inspect STUDY --materials --material-path model.py --definition Model.balance
  --output method-body` writes the selected text without importing or executing the source.
  Caller/configuration reading remains necessary to establish the effective model.
- `temporal_difference` subtracts two columns in each saved row, with declared `time`,
  `reference` and `comparison` roles. It retains the original readings and CSV/NPZ positions,
  uses existing exact-window statistics and saved-sample thresholds, and expresses temperature
  differences in K. Numerical prose and profile panels use the same declaration.
- Optional literature `citation_record` carries supplied CSL metadata. Bibliographies display
  that metadata while the original evidence description remains in the evidence record.
  Shared libraries still work; metadata is not completed from the web or inferred from a claim.
- A figure may set `placement: "section-end"` to appear after its owning section's prose.
  Default layouts, numbering, aspect ratio and font sizes are preserved. This is an explicit
  choice, not an automatic page-height optimizer or a guarantee of fewer pages.
- Packaged Methods, multi-observation, literature and figure guidance connect these tools to
  effective balances, independent diagnostics and readable publication output.

The [recorded tutorial](../../examples/effective-methods/README.md) uses explicitly invented
data and metadata to exercise actual analysis, plots, source binding, four sections, native
Word tables/equations, bibliography display and portable continuation. It is a software example,
not a validated physical model or a demonstration of autonomous scientific discovery.
The [Chinese engineering guide](../tutorials/engineering-trial.md) explains practical trial use.

## Scientific writing exercise

Two isolated first writers used installed v0.19 and candidate v0.20 with identical mature
thermal-probe materials, Python 3.12 and matching main dependency versions. No model was solved
or fitted. Their original outputs were retained, and all five baseline and six candidate Word
pages were inspected. One independent scientific review found the principal values correct
and the overall comparison mixed. The candidate's same-time boundary temperature contrast
added a useful exchange-direction test, but event-relative rear observations could not replace
matched-time mechanism evidence. Its effective boundary/copper definitions and several source
locators also needed correction. These are host reasoning/coverage issues, not solved by more
arithmetic or successful file export.

One separately preserved feedback revision addresses those findings using existing records.
It is not counted as first-draft improvement. This exercise confirms usable source-bound tools,
not automatic physical validation or uniformly improved writing across tasks or providers.

## Scope

The host still chooses evidence, verifies the model's applicability, reads literature and writes
the scientific argument. A temporal contrast is not itself a heat budget, spatial field or
causal proof. Static definition reads do not identify active runtime branches. Solver-native
ingestion, automatic Word-edit merging and scientific equivalence across AI providers remain
outside this release.

## 1. 实际范围

本版主结果是首次充分利用已有证据，而不是增加审批或生成页数。
现有五技能已经描述科学边界，但首次选证动作不具体；资料profile只给有限行预览，
深层设置仍依赖宿主临时检索；已复现的显示规则更新会阻断旧评审actions路径。
因此实施以下相互连接的工作，不重复v0.14已经完成的outline、单位修复和publisher修复。

| 工作 | 落点与负责者 | 可验证结果 |
|---|---|---|
| M1 首次科学选证 | 科学支线修改既有workflow、Methods、literature、figure技能；主控接入现有host prompt | 完整变量/类别阅读、区分解释的证据选择、按实际比较反查方法、文献实质比较和最终版心检查；不是新增警告清单 |
| M2 定向资料定位 | 主控：materials检索helper、inspect CLI及测试 | 显式关键词在全文而非开头预览定位，返回真实文件与行段；选择文件可突破默认发现范围但不猜数据；脚本只读、缺失与截断明确 |
| M3 旧评审显式刷新 | 修订支线：revision与专用refresh helper；主控CLI | 默认旧快照仍严格核对；仅明确选择后在新working重建显示，保留原报告、源/稿和旧引用，列新旧目标；源数据、单位或作者草稿变化不冒充显示更新 |
| M4 首次科学质量评价 | 主控组织隔离宿主首次写作与集中评阅 | 同材料/任务下比较v0.14和v0.15首次选证、方法、文献、图文与人工成本；不提供旧评阅答案，不把修订稿当首稿 |
| M5 投稿形式与端到端 | 主控/交付支线 | 实际图表、公式、DOCX与PDF逐页检查，续改保持非目标内容；必要产品缺陷修代码，论文局部人工改动明确归属 |

分工为主控+科学技能支线+修订支线；两线交付后释放资源给两份隔离首次写作。
共享CLI、manuscript主模块、版本与发布配置由主控负责；不同时修改同一文件。
小批实现与对应测试一起完成，不预设提交数量，不加审批门。

## 2. 实现约束与测试

### 定向定位

复用材料发现、只读和尺寸限制，新增小型文本检索入口，而非第二套RAG或语义评分器。
匹配文档/定义脚本/CSV原文的关键词，显示文件、真实行号和邻近上下文；
支持显式文件选择和结果上限。命中不是物理定义被验证，用户据原记录辨别设置/结果/阶段。
覆盖超过120行的设置、非ASCII路径、多个关键词、显式选择、无命中、截断及不执行Python。

### 评审刷新

显式`--refresh-display`仅用于`review --actions`，不改变默认行为。
旧locator在原快照解析，新的工作稿由当前装配器产生；作者输入、源内容、raw结果及单位、
编号和图件保持一致方可续接。显示字段变化给出旧/新文本，不能把任意自由文本变化当显示。
测试使用合成稿覆盖formatter变化、默认阻断、显式成功、源/作者修改阻断、旧快照不变、
搬迁续改；真实v0.14失败实例做一次定向回放，不重复整篇修订。

### 科学与形式

自动测试只证明确定性接口/计算/文档结构，不证明科学深度。
图件遵循已有公开技能；Methods图须解释实际主比较，关键小值在Word尺寸下可读；
默认正文两字符缩进、段前后0、原生公式、三线表与正常分页，实际渲染验收。
不为修复留白缩小字号，不把截图目检替代源表复核。

## 3. 实际评价与资产

复用P04多图和跨章节经验、散热完整评阅与修订教训、SG_Baffle负面边界。
公开代码/样例使用合成材料；私有原文、算例、数值和本机路径不进入分发物。
首次写作不读取旧成稿、旧评阅或主控答案。采用同一已确认的散热研究材料与研究任务、
相同宿主模型与交付要求；v0.14基线与当前指导分开运行，记录实际输入差异与人工介入。
不虚构精确token等预算一致性；记录可观察工作量，不以运行速度替代质量。
结果解释、资料补取与文献比较应真实执行；源记录中没有的网格/误差等继续如实缺失。
若无法获取重要文献全文，只按实际可访问材料写，不虚称完成贡献核证。

集中评阅双方首次完整输出与必要原始证据，回答：
- 是否主动找到并利用有区分力的现存证据，而非只复述总量？
- 方法和结论是否对应同一case/阶段、算子和比较条件？
- 文献是否说明相近认识及本文增量，而不止“不同/不能验证”？
- 最终图文是否真正可读，格式与符号是否规范？
- 关键科学硬错误、作者纠正和机械协议返工是否减少？

不预定“新版本必胜”。必要时只修有证据的产品问题并做对应回归；
保存首次输出，后续反馈修订明确标注，不能用修订后结果伪装首次优势。
科学/方法不足有真实研究原因时说明其影响；软件发布不等同试验论文投稿批准。

# v0.17研究方向：跨模型协作与瞬态科学写作

2026-10-09。状态：**作者已授权实施；workstream/v017-transient-writing研发中**。
当前基线为v0.16.0及随后仅修改CI测试的main。保留现有55/25/10/10资源优先级。

## 1. 产品定位修正

作者明确接受有较强推理能力的宿主。工具的目标是配合不同厂商、不同地区开发的模型，
让其基于真实材料完成高质量CFD科研工作，而不是为了独立运行重做基础模型。

成熟度重点改为：任务和技能能否跨宿主携带、已有证据是否充分利用、科学输出是否可靠、
真实图文是否合格，以及使用者是否需要开发者反复救场。
宿主品牌、是否提供原生SDK、模型是否具有高水平推理，属于不同问题。

- Python核心负责确定性计算、来源定位、编号和文档结构；同样输入应得到相同结果。
- 宿主负责诊断选择、物理解释、文献比较和专业写作，质量仍会受模型推理能力影响。
- 作者确认科学问题、关键解释和最终论文；不要求其预填完整方法问卷。
- 跨厂商兼容同时检查执行接口和科学输出，不能仅凭API连接或文件生成判定成功。
- 不承诺任意小模型或缺少必要阅读能力的模型都能达到相同科研水平。

## 3. 最小必要研发内容

### A. 可携带的宿主执行约定

复用现有Markdown/JSON/CSV、Skill和CLI接口，准备统一的任务输入及返回说明。
在当前知识/任务包中说明研究问题、当前步骤、相关源文件、计算结果、图件职责和输出格式。
工具名称有平台差异时给出实际CLI/API入口；示例命令包含必需参数并可运行。
不让源文件中的说明获得执行权限，也不要求额外宿主批准层。

支持两种现实路径：

1. 有文件和代码工具的宿主，自行只读定位源材料、调用计算和装配工具。
2. 网页评阅模型，读取同一证据、实际图文和已计算结果，返回科学解释/修改意见。

第二种不能宣称自行执行了计算。能力差异写在任务说明中，不转成一套新的治理级别。
原生多厂商API transport仍待实现；先验证现有可携带路径，若真实执行被连接方式阻断，
选一个可用通用连接切片补齐，不同时重写五套SDK。

### B. 面向真实时序的分析接口

先用电池导出表核对v0.16现有选择/配对/比较能完成哪些任务，只实现实际缺少的运算：

- 时间列、单位、单调性、重复样本、变量域和保存覆盖明确；比较限定于授权共同窗口。
- 支持非均匀时间的声明积分/窗口统计与保存样本峰值，不能把未加权求和当物理时间积分。
- 区分原生事件记录、接受状态首次跨越和后处理插值；插值需明示，缺失事件保持缺失。
- 区分累计J、瞬时W和不同控制体/物种账本；复用已有数值绑定及跨章传播。
- 2×2材料对照优先复用已有数据和配对运算；必要时补同时间、同量、同域的组合对比。
  精确代数分解与独立因果证据分别解读，不将交互方向强制简化成单一材料优劣。

使用原来已有完整结果，不启动COMSOL或单芯新求解、不重新拟合或调整停止条件。
代码资产仅作定义阅读；新分析代码与输入副本放Agent自己的隔离输出目录。

### C. 瞬态论证和论文图文

围绕一个可检验问题组织小节，先选择现象及判别性证据，再确定图/表：

- 工程材料任务：温度随时间的组合效应、主要条件效应及交互项的关系。
- 单芯诊断任务：事件接近而温度状态失配的并存，以及质量闭合对热状态的影响。

按材料完整程度选择一项作为首次写作任务，另一项用于定向回归；不先写两篇全稿。
典型输出可包含时序、多观测对照及局部效应面板，但图型由数据和问题确定，
不能只给事件时刻柱图，也不为“高级感”堆图。
文字应解释物理关系和证据作用，不发布文件检查记录；方法保留必要参数及定义。
继续采用实际版心图件检查、原生表格/数学、正文两字符缩进与零段距，
通过产品实际导出并查看Word/PDF页面。源数据、可运行图脚本及可编辑输出一并保存。

## 4. 评价与分工

先完成一条真实材料到分析、图件和小节的链路；确认入口可用后再跨模型比较。
有条件时选至少两家供应商的可用模型，固定材料、任务、计算结果和主要预算。
记录实际模型/宿主版本、执行能力和提供给它的上下文；未实际运行的模型不列为通过。
目前没有本轮外部模型运行结果，也未预选或调用付费API。

评价由确定性行为和科学作品共同构成：

1. 数值、单位、工况、事件及时间窗口正确，运算可复算。
2. 区分模型角色、拟合/留出、实现验证/实验对照，不遗漏已有关键方法和相反证据。
3. 对材料交互或状态失配形成具体物理解读，不能只增加限制句或罗列数据。
4. 图件与Word页面实际可读，跨图/跨章定义和引用一致。
5. 记录宿主整理量、协议失败、作者科学问题和主控救场；兼容成功不等于效率已提高。

先保存首次输出，再允许一次集中反馈修订。原报告、成稿和主控答案不进入首次写作者的包。
同一材料跨模型写作是兼容/表现评价，不是新的独立实验；不生成任意加权“成熟度分”。

实施采用主控与两条有明确文件边界的短支线：科学时序分析、图文/宿主适配。
公共接口和整合由主控负责，作品评阅按需要使用隔离上下文，不另设常驻审计层。
实施状态见第6节；首次作品与真实结果回归已完成，不重新求解或重拟合。

日期：2026-09-12。状态：M1–M5实现、实际试用、本地安装及候选跨平台CI已通过，已通过PR #3合并；正式交付及最终提交以v0.5.0 release tag为准。

## 1. 与长期目标的关系

长期目标仍是作者在环的 CFD 分析—科研绘图—论文写作—自审—真实返修系统。写作核心仍是准确数据处理、物理解释、规范绘图与学术表达；不变为文档排版器或检查报告生成器。

V0.5.0 做深已有 results-section 路径，不同时开启全稿、原生求解器、VTK 平台、文献管理平台和投稿自动化。资源安排保持科学分析55%、绘图写作25%、易用性10%、必要可靠性10%；它是工作优先级，不是代码行数配额。

遵守 stop-that-shit：本计划列明的必要接口、测试和实际页面检查即可，不另建 registry、批准状态机、评分平台、哈希清单族。遇到实际错误定向修复，不为达到形式上的“零建议”反复审稿。这里的“训练”指真实试用驱动的技能、代码和回归改进，不声称做了模型权重训练。

## 4. 版本范围及最小接口

### 4.1 从原表计算到准确引用（必做）

- 沿用 `table_calculations` 的全行读取、显式列角色/单位/物理域及分组。宿主从现有材料整理输入，只有定义确实影响解释且材料无法回答时询问作者。
- 在现有 evidence 增加一个可选 `result_ref`：计算ID、分组、结果字段、必要的源记录定位和显示精度。继续用 `{{value:ID}}` 写正文/图注，不另造引用系统。
- `value` 与 `result_ref` 二选一，避免手填旧值掩盖计算结果。组装时从当前原表取得绑定值、单位和来源位置，一次取整；缺组/缺值/错误字段给出具体位置，不回退到历史值或零。
- 首批仅支持既有 population/partition 的有限结果：count、sum、mean、CV、area、rate、mean_flux及指定区域的flux/share。区域列表按源记录定位，不靠“看起来第几项”猜区域。禁止可执行表达式/eval。
- CV及份额为无量纲，可显式选择小数或百分比显示；这不是任意单位换算。其余单位按声明角色传递，通量保留rate/area含义；不得自行猜测物性或单位。
- 未绑定自由数字允许存在；评阅仍核其科学含义。软件不声称验证了全部自由文本，也不自动给每个数建新记录。
- 条件性温度一致性工具已有 Python 实现。本版将其纳入测试/技能的实际调用示例，不因定义尚不清楚而自动选择替换值；是否进一步接CLI仅由明确的同域、同变量、同权重输入触发，不为完成案例强行猜面集。

### 4.2 解释深度及宿主易用性（必做）

沿用 question/context/duties 和现有写作 Skill，不再增加一层强制科学表单。宿主在写作前做简短分析：主现象是什么；哪些量最能解释它；图像与指标提供什么不同证据；差异是否来自域/算子/分母；何种机制已有证据，何种仍是候选；本节最后回答了什么问题。

落实为少量通用正反示例：局部强度与积分贡献、源项与输运、归一化变化与绝对量、空间观察与因果。供参考而非照抄成固定句序。CHT内容按需放在现有reference，不把所有论文都引向燃烧或传热。

正文先呈现具体发现和解释，图注给条件/变量/必要读法，证据备注保存未决问题；必要边界放在相关论断处，不重复堆积“不代表/不能证明”。不得以字数增长、更多数学名词或ID引用覆盖声称深度提升。

给定文献已有原文时再核对目标句和适用范围；没有原文不发明引用，也不把文献缺失当作所有结果小节都不能写。修复当前Skill对源码examples的相对链接依赖，把必需操作示例放入已有随包reference，wheel中离线可读。

### 4.3 成稿尺度科研绘图（必做）

- 在现有绘图配置中集中尺寸、字体、轴标、刻度、legend、panel label及色棒参数。默认是可修改的通用审阅配置，不是所有SCI期刊的强制规范。
- 图件输入可声明源图**实际输出宽度**、目标嵌入宽度、已知最小源字号及可编辑资产/本地脚本。缺失字号就明确未知，不通过OCR猜测为精确值。
- 最终字号 = 源字号 × 实际嵌入宽度 / 源图实际输出宽度。输出有效dpi和真实缩放，不能用提高dpi来补救过小文字。单位统一mm/pt，不混用像素字号。
- 新生成图采用固定画布/布局，避免tight裁切后实际宽度与名义figsize不一致；保留tight的既有图以真实导出尺寸计算，不全局改用户图。
- 已有本地脚本视为当前来源；宿主定向修改后重导，不能用模板覆盖作者颜色、刻度、色阶、图型和数据。只有栅格图时只调整允许的嵌入尺寸/位置，不宣称改了图内字体。
- 核心可运行绘图路径补齐SVG/PDF/PNG/TIFF；保留可编辑文字、source data及本地脚本。现有示例已能四格式导出，复用而非重建绘图引擎。
- 图例、panel标号、单位、marker、共有色棒、关键注释按实际图型检查；有限bbox检查加实际预览。不得以“边界未越界”证明没有遮挡，更不能擅自改色标突出效果。

### 4.4 DOCX及基础科学元素（必做，有限支持）

沿用 `write --artifact results-section --docx`，新增 `--layout after-text|near-reference` 的CLI接线。Python端已有布局参数，不重复实现。

主控定义一个小型 publication style 配置用于该小节：页尺寸/页边距、正文/标题/图注/参考文献字体与段距、默认图宽、可读字号下限。默认建议A4、25 mm左右页边距、11 pt正文、10 pt图注；是示例配置，可按期刊改，不标作Energy合规认证。配置随小节保存，避免导出时换了宽度却不知道。

- 后置模式每图与图注形成完整页面单元；近引用模式在首次引用后插入一次。正文保留widow控制，不把每段强制锁为不可分割块而造成大块空白。
- 图像居中，caption与图绑定；设置实际使用的Heading/References字体与颜色，防止主题样式意外回潮。
- 长caption/高图不能靠无限缩小解决。基于可用区域和已声明最小字号发现尺寸冲突时给具体调整建议；caption高度估算不是精确分页证明，实际渲染再检查。
- **基本表格**：复用 `publication/export.py` 的 `ManuscriptTable` 语义（不迁移整个全稿装配器），在小节中提供可编辑DOCX表、表号/题注和引用。有限列宽配置、数值对齐、三线表风格、跨页重复表头、表注；默认不支持合并嵌套复杂表。不能把Markdown竖线文本当原生表。
- **基本公式**：支持小型结构化数学节点：文本/符号、行组合、上下标、分式、根式，转为可编辑OMML；提供对应Markdown可读输出。不开发任意LaTeX解析器。普通变量、希腊字母、指数及分式进入真实公式对象，不以截图或原始LaTeX字符串冒充。超出范围时明确要求给出兼容表达，不静默丢符号。
- 科学数字仍从同一绑定值进入文字/表格/需要的图注，不由导出器擅自改小数或化学符号。表格、公式可选；普通纯文字小节保持兼容。

提供一个可选PDF预览入口：有现成LibreOffice等受支持后端时调用并记录实际后端；没有时照常生成DOCX，清楚提示在Word导出PDF，不假装完成视觉预览。本版不将Office变成核心依赖、不自动安装办公套件。最终候选必须在实际可用环境逐页查看；Word/LibreOffice字体替代或分页不同要准确说明。

### 4.5 评阅包与一次真实试用（必做）

保留完整外审正文及其图表/逐句意见，JSON只作索引和处理辅助，不代替全文。评阅包带实际稿、图、必要原表、计算结果、量的定义及可用脚本。已有 import review 接口仍只收建议，不生成作者批准。

不用新数据证明已知软件行为，但检验写作表现需要一次未给成稿的比较：优先从现有P04尚未用于v0.4写作回放的图9/10等成熟证据中选择一项有价值的任务；主控只准备输入和评价参照，生成者独立上下文只读输入。不为凑新案例重新求解，也不重跑已读答案的Fig.5。

若该候选实际已被用过或证据不足，换另一个现成任务；全部不满足时仅请作者给最低必要材料，不要求重新整理整个案例库。明确这是“留出写作任务”，不是新的独立CFD实验。已有散热修订稿只用于产品集成回归；它证明跨域接线，不能成为本版新盲测成绩。

## 6. 验收标准：科学深度与格式同等需要实际证据

### 科学和写作

1. 关键数字、单位、工况、方向、统计域和量的定义无硬错误；缺失及定义冲突只限制相关论据，不否定整项项目。
2. 计算引用在正文/图注/表格间一致；指标恒等式不是独立机制；单元积分量与密度量、点值与区域统计不混同。
3. 小节解释具体主现象，选择少而有用的定量锚点；有证据时讲清一个诊断差异或竞争解释，不强制制造矛盾。
4. 写作评价给出原文位置和实际理由，分别记录作者改了科学判断、遗漏事实、论证结构还是措辞。没有计时就不报告省时百分比。
5. 初稿与修订稿分别保存；同一案例调好后的表现不包装成独立泛化。局部、整体或机制主张的强度与现有证据匹配。

### 图件、DOCX和引用

1. 设计170 mm、9 pt的图在85 mm嵌入时应得到4.5 pt，而不是因dpi高被误判可读。字号元信息未知时不伪造精确检查结果。
2. 图号/表号/公式引用完整；单位与上下标正确；图例不盖主数据、panel标号不碰撞、色棒与比较基础不变。
3. 近引用与后置模式各有真实测试；长caption与高图不能静默缩到不易读；同类标题、数值、参考文献样式一致。
4. 原生表格有表头及正确对齐；原生公式有可编辑结构，分子/分母和上下标显示完整；不宣称支持任意复杂排版。
5. 实际打开每个代表图和渲染页面，记录真实后端/替代字体；不以图片数量、无越界或文件生成成功替代视觉结论。

### 工程回归与发布

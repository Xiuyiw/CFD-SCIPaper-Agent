# Paired observations and source bound methods

This recorded tutorial uses invented data. It demonstrates the software, not AI writing quality
or physical model validation. A common offset cancels in one temperature contrast; the other
contrast falls outside its conservative reference envelope. The original temperatures remain
in a native table so a zero contrast mismatch does not hide absolute-state disagreement.

```powershell
python examples/paired-observations/run_example.py output-paired-observations
```

Use a fresh output directory. The script uses the actual analysis proposal, compilation,
range-panel generation, manuscript seed, four-section assembly and editable Word APIs.
The selected JSON configuration parameters use json_value_ref rather than hand-copied values.
Methods sources are located under the prepared materials; a selected numeric analysis need
not carry every configuration file. The manuscript seed copies the declared JSON dependency.

The resulting source CSV retains both members' original records and absolute units. Model and
reference contrasts use the declared member order, and temperature differences are in K.
Reference endpoints use conservative subtraction, not a confidence interval. Source data,
standalone plot.py and SVG/PDF/PNG/TIFF travel with the analysis. Preserve local plot edits.

Copy the assembled manuscript directory to continue elsewhere. Reassembly reads its JSON source
again, so changing a declared configuration parameter updates its prose and native table.
It does not recalculate the invented temperature records or rewrite a changed physical argument.
The Word output has native tables and an editable equation, two-character body indentation and
zero body paragraph spacing. Check the actual rendered pages before publication use.
